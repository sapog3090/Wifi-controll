# Цены OnePlus

Android-приложение, которое ищет телефоны OnePlus сразу на **Wildberries, Avito, AliExpress и eBay**
и показывает самые дешёвые предложения — без чехлов, стёкол и запчастей в начале списка.

## Что умеет

- **Поиск по четырём площадкам параллельно.** Каждая площадка отвечает сама по себе: если Avito
  показал капчу, остальные результаты всё равно появятся, а для Avito будет кнопка «Открыть сайт».
- **Отсев мусора.** Заголовок каждого объявления разбирается: телефон это или аксессуар/запчасть,
  какая модель (13, 13R, Nord CE4 Lite, Open…), сколько памяти (12/256, 1 ТБ), новый или б/у.
  Отдельно отсеиваются неисправные и «подозрительно дешёвые» (ниже половины медианы той же модели).
  Всё отсеянное можно раскрыть внизу списка с причиной.
- **Фильтры из выдачи.** Модели и объёмы памяти берутся из того, что реально нашлось, со счётчиками.
- **Новые / б/у.**
- **Отслеживание.** «Следить» сохраняет поиск с фильтрами. WorkManager проверяет его раз в 3–24 часа
  и присылает уведомление, когда минимум обновил исторический рекорд или опустился ниже заданной цены.
- **История цен.** График минимальной цены и медианы по каждому отслеживаемому поиску.

## Установка

APK собирается в GitHub Actions (workflow `OnePlus Prices APK`): вкладка **Actions → последний успешный
запуск → Artifacts → oneplus-prices-apk**. APK подписан отладочным ключом — Android попросит разрешить
установку из неизвестных источников.

Локально: открыть папку `oneplus-price-finder/` в Android Studio или `./gradlew :app:assembleRelease`.

## Устройство

```
core/   чистый Kotlin, без Android: парсеры площадок, разбор заголовков, фильтр, поисковый движок
app/    Android: Jetpack Compose, Room (история), WorkManager (фоновые проверки), OkHttp
```

| Площадка    | Как получаем данные |
|-------------|---------------------|
| Wildberries | JSON-эндпоинт поиска `search.wb.ru`, которым пользуется сам сайт |
| Avito       | HTML выдачи, карточки `[data-marker=item]` |
| AliExpress  | JSON, встроенный в страницу; товары ищутся эвристически (id + название + цена), без привязки к схеме |
| eBay        | HTML выдачи категории 9355, обе вёрстки (`s-item` и `s-card`), цены в $ → ₽ по курсу ЦБ |

`core` покрыт тестами: `./gradlew :core:test`.

## Ограничения

Официальных API для такого поиска у этих площадок нет, поэтому приложение читает те же страницы,
что и браузер. Площадки могут менять вёрстку и включать защиту от ботов — в этом случае приложение
явно пишет, какая площадка и почему не ответила. Парсер, который сломался, обычно чинится
правкой одного селектора в `core/src/main/kotlin/.../sources/`.
